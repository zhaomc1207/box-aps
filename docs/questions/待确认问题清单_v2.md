# 待确认问题清单

## 高优先级

1. 做排程时，真正拿来安排生产的数量，应该用哪个字段：`qty`、`ord_qty`，还是 `line_qty`？
2. 一个订单是否必须一次排完，还是允许先排一部分、剩余留到后面？
3. 一个订单是否允许同时分到多条线生产？
4. 一个订单是否允许拆到多个班次生产？
5. 齐套日期晚于交期的订单，是否仍要安排生产？
6. 如果产能不够，是优先保证交期，还是优先多排数量？
7. FIX 订单是整单固定，还是只固定指定数量？
8. FIX 订单剩余数量是否允许另外安排？
9. FIX 指定的位置如果正好落在预留时间里，以哪个为准？
10. FAI 首件数量是否固定？
11. FAI 首件完成后，后续数量是否必须等到验证通过才能继续生产？
12. FAI 的等待时间是固定规则，还是按项目分别设置？
13. FOT 是否按和 FAI 一样的方式处理？
14. RPQ 是否按和 FAI 一样的方式处理？
15. 绑单订单是否必须一起安排，不能拆开？
16. 产品和线体的对应关系，是“只能排到这些线”，还是“优先排到这些线”？
17. Fast Ship、小单、定制化订单上 Cell 线，是必须还是优先？
18. 当交期要求和 Cell 线规则冲突时，以哪个为准？

## 中优先级

1. 判断一个订单是否按时，是看开工时间还是看完工时间？
2. 一个订单同时有 OTS、FPSD、出货日期时，优先按哪个日期来排先后？
3. 是否允许跨班连续生产？
4. 产能数据是否会按日期和班次变化？
5. Program 变化是否算换线？
6. 同机型但不同颜色是否算换线？
7. 同机型但不同材料项是否算换线？
8. 换线时间为空？

## 低优先级

1. 齐套状态 `C`、`P`、`N` 分别代表什么？
2. 哪些状态代表“可以正式排程”？
3. Pending Pool 里的订单是否进入正式排程？
