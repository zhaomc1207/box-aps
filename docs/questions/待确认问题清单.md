# 待确认问题清单

【排程范围】

1. 本次 BOX 排程是否只覆盖 ASSY 业务？
2. 本次 BOX 排程是否同时包含 Sub 和 Option 需求？
3. 同一次排程里是否允许跨工厂安排生产？
4. 同一次排程里是否允许跨厂区安排生产？
5. 不同业务分类的需求是否允许放在同一套排程结果里一起比较先后？

【需求拆分口径】

1. 一条排程需求是按订单行生成，还是按订单行再拆成多条需求？
2. 同一订单是否允许按 Lot 拆成多条需求分别排产？
3. FAI 需求是否一定要从原订单里单独拆出来？
4. FIX 数量是否一定要从原订单里单独拆出来？
5. 绑单订单是否必须整组一起安排，不能拆开？
6. 一条需求是否允许拆到多条线同时生产？
7. 一条需求是否允许拆到多个班次分别生产？

【交期规则】

1. OTS、FPSD、Ship Date 同时存在时，排程先看哪个日期？
2. OTS 达成是看完工时间，还是看开工时间？
3. FPSD 达成是看完工时间，还是看开工时间？
4. Ship Date 达成是看完工时间，还是看开工时间？
5. D+2 出货订单的判断口径是什么？
6. 已经逾期的订单是否需要自动提到更高优先级？
7. Urgent 订单是否一定排在非 Urgent 订单前面？
8. Pre-Lock 订单是否一定排在普通订单前面？
9. MR Date 受限的订单是否不纳入 OTS 达成考核？
10. MR Date 受限的订单是否不纳入 FPSD 达成考核？

【齐套规则】

1. 未到 MR Date 的订单是否绝对不能开工？
2. 部分齐套的订单是否允许先排一部分数量？
3. 齐套状态为 `Component shortage` 的订单是否允许进入排程？
4. 齐套状态 `C`、`P`、`N` 分别代表什么业务状态？
5. FG Ready Day 是否参与排程先后判断？
6. Pending Pool 里的订单是否参与本次正式排程？
7. 已开立 MO 但还未齐套的订单是否允许保留原排程日期？

【排程优先级】

1. 优先级是完全按配置表顺序执行，还是允许人工覆盖？
2. 同一订单同时命中多条优先级规则时，是否只取最高一条？
3. `Priority Code` 和优先级配置表冲突时，以哪个为准？
4. `qtymax` 和 `ordermax` 两种目标是否可以同时使用？
5. 不同业务分类的订单优先级是否可以直接放在一起比较？
6. `total_index` 是否作为正式排程顺序使用？
7. `Pre Plan` 标记是否会影响订单先后顺序？

【产能限制】

1. UPH 是按整班固定，还是会随日期和班次变化？
2. 同一条线同一班同一机型如果有多条 UPH，应该取哪一条？
3. 班内休息时间是否全部都要从可排产时间里扣掉？
4. 维护时间是否全部都要从可排产时间里扣掉？
5. 预留时间是否允许被人工强制占用？
6. 预留是按整班生效，还是按具体时间段生效？
7. 跨班生产是否允许？
8. 跨班生产时，产量应记到前一班还是后一班？
9. 一条线在同一班内是否允许同时生产两种需求？

【换线规则】

1. 换线时间的单位是否统一按分钟计算？
2. 换线时间是按机型切换计算，还是 Program 变化也算换线？
3. 同机型但不同颜色是否算换线？
4. 同机型但不同材料项是否算换线？
5. `change_rate` 相似度是用于强制限制，还是只用于优先排序？
6. 没有维护到换线时间的机型组合，是否按默认换线时间处理？

【线体匹配与Cell线】

1. 机型与线体的关系是“只能这样排”，还是“优先这样排”？
2. 同一机型是否允许同时分配到多条线生产？
3. Fast Ship 订单上 Cell 线是必须，还是优先？
4. 定制化订单上 Cell 线是必须，还是优先？
5. 小单上 Cell 线是必须，还是优先？
6. 大单是否允许上 Cell 线？
7. Cell 线是否只接小单和快单？
8. `open_type` 中的大线和小线，业务上分别怎么定义？
9. `rolling_flag` 为 1 和为 0 的线，业务处理上有什么区别？

【锁定规则】

1. 已开工单是否允许改日期？
2. 已开工单是否允许改班次？
3. 已开工单是否允许改线体？
4. 已开工单是否允许改顺序？
5. FIX 订单是整单固定，还是只固定指定数量？
6. FIX 订单剩余数量是否允许继续另外排产？
7. FIX 顺序是班内绝对顺序，还是相对顺序？
8. 人工调整结果在下一轮排程里是否必须继承？

【FAI/试产规则】

1. FAI 首件数量是否固定为 2 台？
2. FAI 间隔时间是否固定为 8 小时？

1. 需求合并时，先按 MTM 属性合并，还是先按订单属性合并？

8. Cell 线的循环排序规则是否必须严格执行？
